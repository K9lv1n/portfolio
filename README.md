# Kalvin Developer Portfolio

A polished personal portfolio for AI, data and software internship applications. The site combines a clean editorial layout with a restrained developer aesthetic, image-led project work, light/dark themes and a compact macOS-inspired navigation dock.

## Current project showcase

- AERIS - cold-chain logistics control tower with WhatsApp, Docker, OCR and cloud workflows
- CareSwap - accessibility-first community care platform
- Resume Lens - AI resume review and career guidance application
- Hermes Telegram Email Bot - personal AI email assistant using Telegram, Gmail IMAP, Hermes Agent and DeepSeek

## Page flow

1. Hero

4. Featured Projects

## Highlights

- Four image-led project cards in a clean 2 x 2 layout on desktop
- About Me before project work
- Practical polytechnic skills grouped by AI/ML, data, software and cloud/MLOps
- Top three certifications shown first, with all credentials expandable
- National AI Singapore Olympiad photo slider and reflection

- Light and dark mode with saved preference

## Run locally

No dependency installation is required. The bundled resume download is available at `assets/Kalvin_Chin_Resume.pdf`.

```bash
npm run verify
npm run dev
```

Open the local URL printed in the terminal.

## Important files

```text
src/data.js        Portfolio content
src/app.js         React components and interactions
src/styles.css     Responsive UI and themes
assets/            Portfolio images
```
